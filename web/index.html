            Controls

            Keyboard and gamepad, for both players, and the buttons that choose and go back in menus. In a game, tap Select and Start together, or press F1, for a menu with this screen in it. Hold Select and Start, or press F5, to come back here.In a game, its Controls button has this screen too.

            System files

            BIOS and ROM files some games need. They're found in the library's folders, or added here.

                Any names will do: they're known by what's in them. Add files, folders or zips, like MAME's apple2e.zip, or AppleWin's .rom files.
